04 · MINIMUM IDE

What an IDE
needs to work.

Build from the bottom up. Each step must work before you start the next one.

1 · THE STEPS

1 EDITA window, the text, keys, and Save. (backback, bb-text) Now you have a text editor.
2 COLOURColours, folding and an outline, with no other tool. (bb-syntax) Now it looks like code.
3 FINDOpen a project, see the file tree, find a file, search all files. (bb-dotnet, bb-explorer, bb-search)
4 KNOWAsk Roslyn: errors, suggestions, go to definition, rename. (bb-framing, bb-lsp, bb-intel) Now it is an IDE.
5 BUILDRun dotnet build and list the problems. (the Build panel)
6 DEBUGAsk netcoredbg: breakpoints, step, see values. (bb-dap)
7 TESTThe Test Explorer: find, run and debug tests. (bb-testkit)
8 EXTRASTerminal, Rust, Python, settings, three panes.
UNDER ALLbb-process stops every program backback started. You need it from step 4. Without it, old tools keep running and use your Mac's memory.

2 · MUST HAVE, NICE TO HAVE, NEVER

MUST HAVE

Window and editor · text store · colours · project reader · Roslyn link · start and stop programs · Build · Debug.

NICE TO HAVE

Test Explorer · terminal · find by name · three panes · Rust · Python · follow the Mac's dark mode.

NEVER

Our own C# compiler · MSBuild inside backback · Electron · sending your data anywhere · features nobody asked for.
