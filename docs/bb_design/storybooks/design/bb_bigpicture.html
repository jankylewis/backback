02 · BIG PICTURE

Three layers,
tools below.

The window is on top. Plain logic is in the middle. Below that, other programs do the hard work.

1 · THE BIG PARTS

1 · THE APPthe window you see: editor, file tree, panels
▼ uses
2 · COREtext, colours, languages, files, programs
3 · EDGEtalks to the tools outside
▼ messages, commands, a terminal
4 · TOOLS OUTSIDERoslyn · netcoredbg · dotnet · rust-analyzer · pyright · your shell

The app draws and decides. Core holds the logic. Edge talks to the tools. The tools do the heavy work as their own programs.

5 · HELPERS FOR USbb command · rule checker · code map · colours · Dock icon

You do not see these when you code. They help us build and check backback.

2 · THE PARTS YOU CANNOT REMOVE

TEXTbb-text holds your text. Without it there is no editor.
WINDOWThe backback app draws the window, tabs and panes. Without it you see nothing.
PROGRAMSbb-process starts and stops every tool. Without it, tools keep running after you quit.
LSPbb-lsp and bb-intel talk to Roslyn. Without them it is only a text editor.
PROJECTbb-dotnet and bb-explorer read your .sln and .csproj files and show the file tree.
DEBUGbb-dap talks to netcoredbg. Without it you can build but not debug.

3 · ONE RULE BETWEEN LAYERS

A part may use a part below it, not a part above it. No two parts use each other.

One exception: bb-explorer (core) uses bb-dotnet (edge) to read your project. bb-dotnet uses nothing else.

Core never starts a language tool. Edge never draws on the screen.
