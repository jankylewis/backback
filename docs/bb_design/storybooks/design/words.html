01 · WORDS

The words.

Each word the other pages use, in one plain line.

TOOLS OUTSIDE BACKBACK

WORDWHAT IT MEANS
RoslynMicrosoft's C# compiler. backback asks it what your code means: errors, suggestions, where a name is used.
BuildHostA helper program Roslyn starts to read your project files.
netcoredbgA free .NET debugger. It stops your program at a line and shows the values.
dotnetThe .NET command: dotnet build, dotnet test, dotnet run.
Apex CLIOur own test runner. backback can run tests with it.
rust-analyzer, pyrightThe same kind of helper as Roslyn, for Rust and for Python. Off unless you turn them on.

HOW THEY TALK

WORDWHAT IT MEANS
LSPA shared set of messages between an editor and a language helper such as Roslyn. "Give me suggestions here." "Here are the errors."
DAPThe same idea for debuggers. "Stop at line 12." "Show me the values."
pipeA one-way channel between two programs. backback writes to the tool's input and reads its output.
Content-LengthA small header in front of each message. It says how long the message is.
TRXThe result file dotnet test writes. backback reads pass and fail from it.

INSIDE BACKBACK

WORDWHAT IT MEANS
crateA Rust package. backback is made of 20 of them.
GPUIThe library that draws the window, from the Zed editor. It uses the graphics card.
ropeA way to store text in small pieces. A change in a big file stays fast.
tree-sitterA fast reader for code that runs inside backback. It gives colours, folding and the outline. It needs no other tool.
threadOne line of work inside a program. A program can have many, and they run at the same time.
processA running program. backback is one process; Roslyn is another.
tokioA Rust library for waiting on many things at once without blocking.
PTYA fake terminal device. The terminal panel runs your shell in one.
owned groupA group of programs backback started. backback must stop the whole group.
guardA tiny watcher program. If backback dies, it stops everything backback started.
CharIdx, LspPointTwo ways to say where you are in a file. The editor counts characters; LSP counts lines and columns.
tickA language you turned on in the language list. A language that is not ticked starts nothing.
