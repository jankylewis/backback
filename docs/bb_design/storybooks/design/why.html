Why backback.

On a Mac, there is no small, free app for C# anymore.

1 · THE OLD MAC APPS FOR C# ARE GONE.

Microsoft stopped Visual Studio for Mac in August 2024. MonoDevelop has not been updated since January 2020.

The apps that are left are heavy. VS Code runs more than 20 programs at once. Rider is big, and you must pay for it.

2 · THE HARD PARTS ARE ALREADY FREE.

Roslyn is Microsoft's C# compiler. It can tell an app what your code means. It is free.

netcoredbg is a free debugger for .NET. The dotnet command builds, runs and tests your code.

So backback does not do these jobs again. It only talks to these tools.

3 · IT IS FAST BECAUSE IT DOES LITTLE.

backback itself only does four things: it holds your text, draws the window, searches, and starts and stops the other tools. Typing never waits for another tool.

Our goals, which we measure: ready to type in 0.3 seconds or less. A key shows on screen in 8 ms or less (half of the time). Less than 150 MB of memory when Roslyn is not running.

4 · SMALL ON PURPOSE.

C# comes first. Mac only. Few features. You can also turn on Rust and Python. They start only when you tick them in the language list.
