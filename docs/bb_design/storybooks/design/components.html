4 · WHO USES WHOM

backback (the app) uses every package below, but not the bb command
bb-intel   uses bb-lsp, bb-dotnet, bb-cargo, bb-python, bb-text
bb-lsp     uses bb-framing, bb-dotnet, bb-process
bb-dap     uses bb-framing, bb-process
bb-testkit uses bb-dotnet, bb-process
bb-cargo   uses bb-process, bb-testkit      bb-python uses bb-cargo, bb-testkit
bb-syntax  uses bb-text, bb-lang          bb-explorer uses bb-dotnet
bb-text, bb-process, bb-lang, bb-search, bb-framing, bb-dotnet use nothing

From bb map. The packages that use nothing are the easiest to test.
