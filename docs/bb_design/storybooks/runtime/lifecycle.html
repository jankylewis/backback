07 · START + QUIT

Start clean,
leave nothing.

backback starts in a fixed order. When it ends, every program it started must end too.

1 · START, IN ORDER

1 PATHRead the PATH from your shell (5 second limit). An app started from the Dock gets a short PATH and cannot find dotnet (BB-BUG-009).
2 CLEANLook for notes left by an earlier backback that died. Stop the programs it started, but only if they are still the same programs.
3 GUARDStart this backback's guard.
4 WHATDecide what to open: a project, a folder, or the start page.
5 LOOKbb-detect looks for languages. The file tree loads.
6 SIGNALSGet ready for stop signals from macOS, so they stop the tools too.
7 WINDOWThe window opens. Only the ticked languages start their tools.

Steps 1-3 run before any other thread starts. That keeps them simple and safe.

2 · THE LANGUAGE LIST DECIDES WHAT STARTS

C# tickedRoslyn starts
Rust not tickednothing starts
Python not tickednothing starts, no marks

Your choice is saved for each folder. Python is off at first, unless the folder has only Python.

3 · MANY WAYS TO END, ONE RESULT

HOW IT ENDSWHO STOPS THE TOOLS
Cmd+Qbackback stops every group itself. The guard checks after.
A stop signalbackback catches the signal, stops every group, then exits.
A crashbackback cannot clean up. macOS closes the guard's pipe, and the guard stops every group.
Force quit, kill -9The same: the guard asks each group to stop, waits 1 second, then forces it.
The guard dies tooThe next time backback starts, step 2 cleans up.

4 · WHAT BACKBACK SAVES ON YOUR MAC

In ~/Library/Application Support/backback: your Recent list, your language choices, exception breakpoints, and one note for each running backback that lists the programs it started.

backback sends nothing over the internet. Only dotnet and NuGet go online, to get packages.
