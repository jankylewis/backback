THREE RULES FOR THREADS

NO WAITThe main thread never waits for a tool. Typing, colours and drawing finish in one frame.
MESSAGESThe window sends questions to a worker. The worker sends answers back. They share no data, so they never fight over it.
ONE LOCKOnly one place uses a lock: the list of questions that wait for an answer. Nothing holds that lock while it waits.
