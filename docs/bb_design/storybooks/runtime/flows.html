06 · FLOWS

Four things you do,
step by step.

Press STEP to see the next step. Green steps happen on the main thread. Yellow steps happen on another thread or in another program.

1 · YOU TYPE ONE KEY

MAINThe window gets the key. The text changes at once, even in a very big file.
MAINtree-sitter updates the colours, only for the lines you can see. This takes microseconds.
MAINThe screen draws. Goal: 8 ms or less from key to screen.
bb-intelAfter that, backback tells Roslyn "the file changed".
ROSLYNRoslyn checks the code and sends back any errors.
MAINThe window picks up the errors and draws red lines on the next frame.

The first three steps never wait. Roslyn can be slow, and typing still feels instant.

2 · YOU ASK FOR SUGGESTIONS

MAINYou press Ctrl+Space. backback changes the cursor position into the form LSP uses (line and column).
bb-intelThe question goes to the tool for this file's language. It gets a number and a time limit.
WRITEA small task adds the length header and sends the question to Roslyn.
READAnother task reads the answer. It finds the question with the same number and hands the answer over.
MAINThe list of suggestions shows. If the time limit runs out first, you see a message. The window never freezes.

3 · YOU OPEN A PROJECT

MAINbackback reads the .sln and project files. The file tree shows at once.
MAINThe language list shows the languages it found. Your last choice for this folder is already ticked.
THREADSOne worker starts for each ticked language. Languages that are not ticked start nothing.
ROSLYNRoslyn starts in its own group. It reads your projects and reports how far it is.
MAINThe status changes from loading to ready. Code help is on.

4 · YOU PRESS F5

bb-debugThe bb-debug thread starts. It builds your program with dotnet build.
bb-dapIt starts netcoredbg, tells it to run your program, and sends your breakpoints.
PROGRAMYour program runs until it reaches a breakpoint.
MAINbackback hears "stopped". The editor jumps to the line. The panel shows the call stack and values.
MAINStep, Continue and Set Next Statement go to netcoredbg as messages. Stop ends the whole group.
