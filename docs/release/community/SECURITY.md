# Security Policy

## Supported versions

backback is pre-release software. Only the latest `master` code is maintained.

## Report a vulnerability

Email `jankylewis.se@gmail.com` with the affected version, steps to reproduce,
and impact. Do not open a public issue for an unpatched vulnerability.
The maintainer will acknowledge the report and coordinate a fix and disclosure.

Do not send credentials, auth stores, or real customer data in a report.
